# 材料填写规范

## 一、三种填写方式（红/蓝/黑）
- **红色字体 = 个人填写**：由申请人本人填写（入党申请书、自传、思想汇报、入党志愿书个人部分、转正申请书等）。
- **蓝色字体 = 组织审批**：由党组织填写并盖章（政审表、预审表、综合审查报告、党委审批意见等）。
- **黑色字体 = 支部填写**：由党支部填写、不需上级组织审批（各类登记表、会议记录、公示表、测评表、汇总表等）。

## 二、常见格式要求（规则引擎检查项）
| 检查项 | 规范 |
|---|---|
| 标题 | 居中，二号小标宋或黑体 |
| 正文字体 | 仿宋_GB2312（或仿宋） |
| 正文字号 | 三号（16pt） |
| 一级标题 | 三号黑体 |
| 二级标题 | 三号楷体 |
| 行距 | 固定值 28–30 磅 |
| 落款 | 正文右下方：署名 + 日期（如"申请人：{{姓名}}　{{日期}}"） |
| 日期 | 统一格式，可用阿拉伯数字或中文数字 |

## 三、常见易错点（供 AI 质检提示参考，只列问题不改原文）
1. **逻辑矛盾**：时间线前后矛盾（如转正申请日期早于预备期起始）、阶段与材料不匹配（积极分子阶段就出现转正材料）。
2. **表述不规范**：称谓/身份混用（"申请人""积极分子""预备党员"张冠李戴）、单位/支部名称不规范、错别字与病句。
3. **格式缺失**：缺落款、缺日期、标题未居中、字体字号不符。
4. **内容缺失**：必备段落缺失（如入党申请书缺"对党的认识""入党动机"等要素）。
5. **个人信息不一致**：姓名、学号、院系与档案不一致。

## 四、脱敏要求
- 材料模板、示例、测试数据一律用 `{{占位符}}`（`{{姓名}}`、`{{学号}}`、`{{院系}}`、`{{支部}}`、`{{日期}}`）。
- 示例人物一律化名（张某、李某、王某）。
