# 发展党员流程图（五阶段）

> 依据《中国共产党发展党员工作细则》及学校《发展党员流程图》整理。示例人物一律化名。

## 阶段一：申请入党
- 节点 1：提出入党申请（个人递交《入党申请书》）。
- 节点 2：首次谈话（党组织收到申请后 1 个月内派人谈话）。

## 阶段二：积极分子的确定与培养考察
- 节点 3：确定入党积极分子（党员推荐 / 群团组织推优，支委会研究决定并报党委备案）。
- 节点 4：确定培养联系人（指定 1–2 名正式党员）。
- 节点 5：积极分子的培养与考察（培养教育 ≥ 1 年；每季度至少 1 篇思想汇报；参加党课并结业）。

## 阶段三：发展对象的确定与考察
- 节点 6：确定发展计划（年初或上年底）。
- 节点 7：第一次座谈会（征求党内外群众意见）。
- 节点 8：确定发展对象（培养考察 ≥ 1 年后，支委会研究、公示、报党委备案）。
- 节点 9：发展对象的呈报。
- 节点 10：第一次公示。
- 节点 11：确定入党介绍人（两名正式党员）。
- 节点 12：发展对象的审查与教育（政治审查、函调外调、综合审查报告；短期集中培训）。
- 节点 13：两级预审（第一级支部预审 → 第二级党委预审）。
- 节点 14：材料上报上级党委。

## 阶段四：预备党员的接收
- 节点 15：填写入党志愿书（发展前填写）。
- 节点 16：支部大会讨论并表决（第一次投票）。
- 节点 17：党委会审批（1 个月内完成审批）。
- 节点 18：入党宣誓（编入党支部后）。

## 阶段五：预备党员的培养考察与转正
- 节点 19：预备党员的培养与考察（预备期 ≥ 1 年）。
- 节点 20：提出转正申请（预备期满前 1–2 周）。
- 节点 21：转正答辩。
- 节点 22：第二次座谈会（党内外群众意见）。
- 节点 23：支部大会讨论转正并表决（第二次投票）。
- 节点 24：转正公示。
- 节点 25：党委会审批转正。
- 节点 26：材料归档（存入个人档案）。

## 关键时间要求
| 要求 | 对应节点 |
|---|---|
| 收到申请后 1 个月内谈话 | 首次谈话 |
| 培养教育考察 ≥ 1 年 | 积极分子培养考察 |
| 积极分子到发展对象 ≥ 1 年（含至少 6 个月重点考察） | 确定发展对象 |
| 发展对象确定后 2 年内完成发展 | 发展对象审查教育 |
| 党委审批预备党员 ≤ 1 个月 | 党委会审批 |
| 预备期 ≥ 1 年 | 预备党员培养考察 |
| 预备期满前 1–2 周提出转正申请 | 提出转正申请 |

## 特殊情形
- 毕业生：全部党员材料寄往新单位（扫描 6/7 份核心材料归档：入党志愿书、入党申请书、政审材料、转正申请书、入党积极分子考察登记表等）。
