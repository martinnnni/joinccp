# 本地开发运行手册（Windows）

本文件面向学生维护者，说明本机如何启动/停止网站及其依赖（MySQL、Redis）。

## 一、目录与端口
| 组件 | 位置 / 端口 | 说明 |
|---|---|---|
| 项目代码 | `D:\党员发展培养网站` | Django 项目 |
| Python 虚拟环境 | `D:\党员发展培养网站\.venv` | 已装好全部依赖 |
| MySQL（便携版） | `D:\party-local-services\mysql`，端口 **3306** | 数据在 `D:\party-local-services\data\mysql` |
| Redis（便携版） | `D:\party-local-services\redis`，端口 **6379** | 仅 Celery 定时任务用 |
| 网站 | http://127.0.0.1:8000 | Django runserver |
| 服务日志 | `D:\party-local-services\logs` | 各服务 .out.log / .err.log |
| PID 记录 | `D:\party-local-services\data\pids` | 启停脚本用 |

> 为什么服务放 `D:\party-local-services` 而不是项目目录：项目路径含中文，MySQL 在中文路径下容易出问题，放 ASCII 路径最稳。

## 二、一键启动 / 停止
在项目根目录执行（PowerShell）：
```powershell
# 启动 MySQL + Redis + 网站
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1

# 启动时同时带上定时任务（Celery）
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1 -WithCelery

# 停止全部
powershell -ExecutionPolicy Bypass -File scripts\stop-local.ps1
```
启动成功后浏览器打开 http://127.0.0.1:8000 。

## 三、手动启动（脚本不可用时）
按顺序在项目根开三个终端：
```powershell
# 1) MySQL
D:\party-local-services\mysql\bin\mysqld.exe --defaults-file=D:\party-local-services\mysql\my.ini

# 2) Redis
D:\party-local-services\redis\redis-server.exe D:\party-local-services\redis\redis.conf

# 3) 网站
.venv\Scripts\python manage.py runserver 127.0.0.1:8000
```

## 四、数据库初始化（通常已自动完成）
```powershell
.venv\Scripts\python manage.py migrate
.venv\Scripts\python manage.py seed_flow
```
- `migrate` 建表；`seed_flow` 写入 5 阶段 / 26 节点 / 44 材料。
- 本地 MySQL 的 root 是空密码（仅本机）。

## 五、账号
- 管理员：`admin` / `Admin@123456`（本地演示用，上线前务必改）。
- 学生：访问 `/register/` 自行注册，会自动建档案。

## 六、Redis / Celery 说明
- Redis 只服务「定时提醒」。不启动 Redis 网站也能正常用，只是临近截止提醒不会自动生成。
- 也可不跑 Celery，手动执行一次提醒：
  ```powershell
  .venv\Scripts\python manage.py scan_reminders
  ```

## 七、Neo4j 说明
- 本机未安装 Neo4j（官方下载源被 403 封禁）。
- 网站不依赖它：档案页「下一步」会**自动降级用 MySQL** 查询，功能正常。
- 想启用图查询：在 `.env` 填 `NEO4J_URI`（如 `bolt://127.0.0.1:7687`）并启动 Neo4j 即可；生产 Linux 机按 `deploy/README.md` 用 apt 安装。

## 八、常见问题
1. **端口被占用**：改 `my.ini` 的 `port` / `redis.conf` 的 `port`，同步改 `.env` 的 `MYSQL_PORT` / `REDIS_URL`。
2. **MySQL 起不来**：看 `D:\party-local-services\logs\mysql-error.log`；常见是数据目录残留，删掉 `data\mysql` 重新 `mysqld --initialize-insecure`。
3. **pymysql 认证失败**：`my.ini` 已设 `mysql_native_password`；仍失败则 `mysql -u root` 后执行
   `ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '';`
4. **AI 不回应**：`.env` 的 `DEEPSEEK_API_KEY` 没填时，质检/导师会显示「AI 暂不可用」降级提示，属正常。
5. **换电脑/重装**：服务目录 `D:\party-local-services` 可整体删掉重建；项目侧只需重建 `.venv`。
