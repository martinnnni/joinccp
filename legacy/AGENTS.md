# AGENTS.md · 工程规范（每次上下文必读）

本项目：党员发展计划辅助系统。**开发在 Windows，生产在 Linux（无头服务器）**——所有代码、脚本、配置默认按"能在 Linux 上原样运行"编写。业务背景与阶段计划见 `docs/项目计划.md`。

## 路径
- 禁止硬编码 `\` 或 `/` 拼路径：Node/TS 用 `path.join()` / `path.resolve()`；Python 用 `pathlib.Path` / `os.path.join()`。
- 禁止硬编码绝对路径（`C:\...`、`/home/...`）。运行时路径从项目根推导（`import.meta.url` / `__dirname` / `process.cwd()`）或环境变量（`HOME` 等）构建。
- 路径与配置常量集中在配置模块，不散落业务代码。

## 大小写
- Linux 文件系统区分大小写：文件名与导入路径必须逐字符等于磁盘实际名称（含扩展名）。新建文件后、引用前先核对。

## 换行符
- 仓库文本一律 LF；`.sh` 必须为 LF（CRLF 在 Linux 下无法执行）。Windows 专属脚本（`.bat/.cmd/.ps1`）用 CRLF。
- 由根目录 `.editorconfig` 与 `.gitattributes` 机械强制（已配置），不靠自觉。

## 权限与运行
- 部署脚本中显式 `chmod +x` 可执行文件；服务以非 root 用户运行；日志/数据目录在部署脚本中明确属主与读写权限。

## 平台差异
- 禁止拼接 shell 字符串调用外部命令；优先用语言内置跨平台库。
- 确需平台分支时集中隔离（如 `platform/` 模块、`#ifdef _WIN32`），业务代码里不散落 `if (win)`。

## 依赖
- 含原生扩展的依赖（`.node` / `.pyd`）不能拷贝迁移：到 Linux 必须重新安装/编译（如 `npm ci`）。
- 锁文件必须提交（package-lock.json / pnpm-lock.yaml 等），保证两端版本完全一致。

## 验证
- 涉及部署 / 脚本 / 文件操作的改动，交付前在 WSL 2 中跑一遍构建、测试、启动，提前暴露大小写、路径、权限问题。
- 若配置 CI，流水线跑在 Linux runner 上。

## 技能加载（党员发展计划）
- 处理党员发展/入党流程、党务材料类问题前，先读 `skill/党员发展计划/SKILL.md`，按其指引加载 `knowledge/` 知识库文件，再按其回答规范作答。
- 写前端/界面代码（页面、组件、样式）前，先读 `skill/frontend-design/SKILL.md`（Anthropic 官方前端审美技能，2026-11-13 经镜像取自 anthropics/skills 仓库），先定美学方向再动手，禁 AI 通用审美（紫色渐变/Inter/三栏卡片）。

## 本项目红线
- 不修改、不依赖 DSH 安装目录（app.asar）；一切自研资产放本项目目录。
- 脱敏红线：知识库 / 示例 / 测试数据一律化名（张某、李某），材料模板个人信息用 `{{占位符}}`；涉密材料不入对话。详见 `docs/项目计划.md` §四。
