# 党员发展计划辅助系统

![中国民航大学校园](public/campus-hero.webp)

党员发展计划辅助系统面向中国民航大学学生、辅导员和管理人员，用来集中管理培养流程、学生档案、材料提交、阶段审核和站内通知。

这个系统想解决的不是“把线下表格搬到网页上”，而是把原本分散在名单、文件夹和聊天记录里的信息连起来。学生能看清自己走到哪一步，辅导员能快速找到需要处理的人和材料，重要操作也能留下完整记录。

## 学生端

学生使用学号登录，第一次登录必须修改初始密码。进入系统后可以：

- 查看当前培养阶段、所在节点和培养进度。
- 查看已经提交和仍需准备的材料。
- 上传 Word、PDF 或图片材料，并保留历史版本。
- 按培养阶段下载所需表格。
- 接收辅导员发送的站内通知。
- 使用成长导师查询流程、填写要求和系统操作方法。
- 上传材料内容，检查材料类型、填写规范和疑似错别字。

学生只能查看自己的档案、材料和通知。

## 辅导员端

辅导员负责维护所属专业学生的培养信息，可以：

- 上传 Excel、Word 或 PDF 名单，识别姓名和学号后批量创建学生账号。
- 补充学生的学院、专业、班级、年级和培养信息。
- 批量审阅材料、推进培养阶段和发送站内通知。
- 查看并下载所属专业学生提交的文件。
- 上传本院系使用的表格。
- 查看每一步后台操作记录。
- 使用办公助理完成批量登记、信息更新、材料处理和密码重置等工作。

办公助理不会直接执行高风险操作。它会先整理任务、列出影响对象和准备执行内容，辅导员确认后才会真正写入系统。

## 管理员端

管理员负责维护系统的基础数据和全局账号，可以：

- 管理学院、专业、班级、学生和辅导员。
- 创建辅导员邀请码。
- 批量创建、回收和恢复账号。
- 查看全部院系的培养进度与材料情况。
- 上传全校通用表格。
- 查看全站操作日志和账号回收站。

## 成长导师

成长导师会根据问题决定是否查询知识库。

涉及培养流程、材料要求、系统使用或学生个人进度的问题，会优先检索培养规范、材料清单、系统指南，以及当前学生有权限查看的档案信息。检索到依据时，回答会附上来源；资料里没有确切信息时，会明确说明知识缺口，不把通用回答伪装成学校规定。

成长导师还可以检查 Word 和可读取文字的 PDF。检查过程会先识别材料类型，再查询对应填写规范，最后指出疑似错别字、缺失内容和不符合要求的填写方式。

## 办公助理

办公助理只向辅导员和管理员开放。它理解的是实际工作任务，而不只是固定按钮，例如：

- “把这份名单里的学生批量登记到信息与计算科学专业。”
- “提醒还没有提交思想汇报的学生。”
- “把这几名学生推进到下一培养阶段。”
- “下载张三最近提交的材料。”
- “重置学号 123 的登录密码。”

涉及批量修改、删除、阶段推进、通知发送和密码重置时，系统会先生成待确认计划，并再次检查操作者的院系权限。

## 材料与表格

系统把材料分成两个入口：

- “材料提交”用于学生提交个人培养材料，辅导员可以审阅和下载。
- “资料下载”用于按阶段提供需要填写的表格，管理员可以上传全校表格，辅导员可以上传本院系表格。

上传文件不会获得公开下载地址。每次查看或下载都会重新检查登录身份和院系权限。

## 培养流程

系统围绕五个主要阶段组织学生档案和材料：

1. 申请入党
2. 积极分子培养
3. 发展对象考察
4. 接收预备党员
5. 培养考察与转正

每个阶段包含对应节点、材料和处理状态。辅导员推进阶段后，学生端会同步更新，并收到相应站内通知。

## 权限与记录

- 学生只能访问自己的信息。
- 辅导员只能管理所属专业的学生。
- 管理员可以管理全部院系。
- 文件下载、批量操作、账号修改和失败请求都会留下访问记录。
- 删除账号时先进入回收站，相关材料和历史记录不会立即消失。
- 聊天记录只保留在当前页面，不写入学生档案。

## 项目边界

这个系统是培养工作辅助工具，不代替党组织审核，也不把 AI 回答视为正式组织意见。流程和材料要求应以学校党委组织部及所属党组织的最新规定为准。

项目仍在持续完善，重点包括材料识别准确率、移动端体验、批量操作稳定性和更多真实工作场景。
