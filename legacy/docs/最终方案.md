## 三、暂缓项（不配也能用）
### 1. Neo4j 图数据库（本机装不了）
- **原因**：官方下载源 `dist.neo4j.org` 返回 403，本机无法获取安装包。
- **影响**：无。代码已自动降级为 MySQL 查询（档案页「下一步」正常）。
- **以后怎么补**：生产 Linux 服务器按 `deploy/README.md` 用 apt 安装；或本机装 Docker 后跑 Neo4j 容器，再把 `.env` 的 `NEO4J_URI` 填成 `bolt://127.0.0.1:7687`。

### 2. DeepSeek AI Key（需你提供）
- **原因**：`DEEPSEEK_API_KEY` 需要真实 Key，你不给就没法调。
- **影响**：材料质检的「AI 建议」、成长导师聊天会显示降级提示（不报 500，页面正常）。
- **以后怎么补**：`.env` 填 `DEEPSEEK_API_KEY=sk-...`，重启网站即可。

### 3. Celery 定时提醒的「自动常驻」
- **现状**：Redis 已装，但 Celery worker/beat 未设为开机常驻。
- **不影响**：网站正常运行；提醒可手动触发。
- **怎么用**：启动脚本加参数 `-WithCelery`，或手动执行 `python manage.py scan_reminders`。

### 4. 生产部署（Linux / Gunicorn+Nginx+systemd）
- **原因**：属于「上服务器」阶段，本地不做。
- **已就绪**：`deploy/` 下 systemd、nginx、初始化、备份脚本 + 部署文档齐备。

## 四、日常使用（三步）
```powershell
# 1. 在项目根目录打开 PowerShell，启动全部服务
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1

# 2. 浏览器访问
#    http://127.0.0.1:8000

# 3. 用完停止
powershell -ExecutionPolicy Bypass -File scripts\stop-local.ps1
```
- 管理员：`admin` / `Admin@123456`
- 学生：访问 `/register/` 自行注册（会自动建档）

## 五、上线 Linux 时（暂缓，按文档做）
1. 服务器初始化：`deploy/init_server.sh`（或按 `deploy/README.md` 手动）。
2. 建库、填 `.env`、`migrate` + `seed_flow`、`collectstatic`。
3. 装 systemd 服务（gunicorn/celery/celery-beat）+ Nginx。
4. Neo4j 用 apt 安装；备份用 `deploy/backup.sh`（建议每日 cron）。

## 六、说明与注意
- **服务目录在 `D:\party-local-services`（不是项目内）**：因为项目路径含中文，MySQL 在中文路径下易出错，故服务放 ASCII 路径。
- **本会话沙箱限制**：当前会话只能写项目目录，不能写服务目录，因此我无法代为启动；你在自己的 PowerShell 里运行上面的命令即可。
- **本地 root 是空密码**：仅限本机开发；上线务必改密码并换 `SECRET_KEY`。
- **AI 未启用**时，质检/导师走降级提示属正常设计，不是报错。
